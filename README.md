# 纸间 · 小票生成器

**把每一笔，整理成一张好看的小票。**

[在线使用](https://pomecro.github.io/zhijian-receipt/) · [项目仓库](https://github.com/Pomecro/zhijian-receipt)

纸间是一款简洁的在线小票制作工具。自由编辑项目与金额，实时预览票面，一键保存高清 PNG。无需注册，无需安装，打开网页即可使用。

## 功能亮点

- **实时双栏预览**：同时查看完整小票与可滚动的票面细节。
- **自动计算金额**：支持项目增删、负数抵扣，以及自定义加急倍数。
- **自由编辑内容**：自定义抬头、时间范围、备注和页脚。
- **顶部与尾部图片**：分别添加图片，按比例展示，不裁剪。
- **自动本地暂存**：恢复同一浏览器、同一网址下的上次编辑内容。
- **高清 PNG 导出**：按完整票面导出，不受预览滚动位置影响。
- **一键重置**：恢复默认内容并清空暂存图片。
- **响应式布局**：适配桌面与手机浏览器。

## 如何使用

1. 打开网站，填写小票抬头和时间范围。
2. 添加项目名称与金额，按需开启加急费和备注。
3. 如有需要，添加顶部图片和尾部图片。
4. 查看右侧预览，点击 **保存小票 PNG**。

支持 PNG、JPG、WebP 图片，单张不超过 20 MB，高度不超过宽度的 8 倍。

## 本地暂存说明

小票文字保存在浏览器 localStorage，图片保存在 IndexedDB。小票内容与导入图片由网页在本地处理，不会由应用上传到服务器。

暂存不会跨设备、跨浏览器或跨网址同步；清除网站数据或使用隐私浏览可能导致暂存丢失。需要长期保存的小票，请及时导出 PNG。

## 本地使用

下载源码后，直接用 Chrome、Edge 等现代浏览器打开 `index.html` 即可，无需安装依赖或执行构建命令。

## GitHub Pages 部署

本项目是纯静态网页，没有外部脚本、字体或图片依赖，不需要数据库、API 密钥或环境变量。

1. 将仓库文件放在默认分支的根目录。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 **main** 分支和 **/ (root)** 目录，点击 **Save**。
5. 等待发布完成，使用 Pages 页面显示的网址访问。

`.nojekyll` 用于按静态文件直接发布。后续更新 `index.html` 并提交到发布分支，GitHub Pages 会重新部署。
